## 1. AI/プロンプト系ショート動画

### 伸びる構成型一覧（[WebSearch済] / [WebFetch済]）

#### 型1: 「知らないと損」型
- **フック**: 「この設定を知らないと損します」「9割が知らずに損してる設定」（損失回避心理）
- **展開**: 30秒以内に具体的なプロンプト or ツール操作を実演
- **オチ**: 「これ使えばあとは自動でできる」＋保存/フォロー誘導CTA
- **なぜ伸びるか**: 損失回避バイアス。視聴完了率が高い。[WebFetch済 active-note.jp]
- **例**: 「ChatGPTのこのプロンプト、知らないと3時間損します」

#### 型2: Before/After（変換型）
- **フック**: 先に驚くべき結果を見せる（「この雑な指示が…」）
- **展開**: 「ビフォーのプロンプト → AIの出力（イマイチ）→ 改善後のプロンプト → 激変した出力」
- **オチ**: 改善後の出力を見せ、「保存してね」CTA
- **なぜ伸びるか**: 変化の可視化。ビジュアルで差が分かりやすい。[WebFetch済 miraflow.ai]
- **例**: 「Claude Codeに雑に頼んだ結果 vs ちゃんと指示した結果」

#### 型3: AIツール比較型
- **フック**: 「ChatGPT vs Claude どっちが副業向き？」（対立構造でスクロール止め）
- **展開**: 同じ入力を複数ツールに入れてアウトプット比較。ジャッジは明快に
- **オチ**: 「用途別ならClaude一択の理由」等の結論を言い切る
- **なぜ伸びるか**: 比較は保存率が2.5倍。[WebFetch済 virvid.ai]
- **例**: 「副業応募文を3つのAIに書かせた結果」

#### 型4: 「AIで作ったもの紹介」型（実演型）
- **フック**: 完成物を最初に見せる（「Claudeに頼んだらこれが3分でできた」）
- **展開**: 実際の操作画面を早回しで見せる（コード/画像/文章等）
- **オチ**: 「手順をコメントに貼ります」or「詳細はnoteで」
- **なぜ伸びるか**: 具体性と再現性の訴求。プロセスへの好奇心。[WebSearch済 college-sales.com]

#### 型5: 「プロンプト1個紹介」型（ランキング型亜種）
- **フック**: 「このプロンプト1つで副業案件の80%対応できる」
- **展開**: プロンプト内容をテロップで見せながら解説
- **オチ**: 「保存してください」+ 動画リスト誘導
- **なぜ伸びるか**: コンパクト・すぐ使える感。保存率が高い。[WebSearch済 uravation.com]

### 共通フック法則（[WebFetch済] addness.co.jp・virvid.ai）

- 冒頭3秒で「結果/結論」を提示してから理由を語る（PREP法の圧縮版）
- 「71%の視聴者は最初の3秒で離脱を決める」[WebFetch済 virvid.ai]
- 「直接呼びかけ型フック（If you're [ターゲット], stop scrolling!）は91.7%注目率向上」[WebFetch済 virvid.ai]
- NG開始: 「こんにちは、〇〇です」「今回は〇〇を解説します」[WebFetch済 active-note.jp]

## 2. 副業・収益化系ショート動画

### 伸びる構成型一覧（[WebSearch済] / [WebFetch済]）

#### 型1: 「N万円稼いだ実録」型（変換型＋ストーリー型）
- **フック**: 「2月は0円だったのに3月は14万になった理由」（具体数字+対比）
- **展開**: 何を変えたか（1つだけ）→ビフォー状態 → 転換点 → 結果
- **オチ**: 「たった1つのことを変えたら」系の結論＋詳細はnote/Brain誘導
- **倫理ライン**: 数字は実績のみ。「稼げます」は言わない。「わたしはこうなった」で通す
- **景表法留意点**: 「誰でも稼げる」「確実に稼げる」はNG。[WebSearch済 metro.tokyo.lg.jp]

#### 型2: 失敗談型（共感＋反面教師）
- **フック**: 「副業3ヶ月やって0円だったときの話」（最悪の結末から始める）
- **展開**: 何が間違ってたか → その後どう変えたか
- **オチ**: 「同じミスしないでね」→ CTA
- **なぜ伸びるか**: 成功自慢より失敗談の方がコメントが集まる。共感がベースになる。[WebSearch済 note.com/talented_renya]
- **実例**: 「15本投稿して再生数1,847回・収益0円だった実録」[WebSearch済 note.com/freelife_creator]

#### 型3: 「これだけやればOK」チュートリアル型
- **フック**: 「副業で月5万稼ぐためにやることは3つだけ」
- **展開**: 箇条書きを1つずつ画面表示しながら解説。全部で45秒以内
- **オチ**: 「この順番が大事」で記憶に残す
- **なぜ伸びるか**: 一覧型は保存率2.5倍。[WebFetch済 virvid.ai]

#### 型4: 「正直レビュー」型（副業情報への反論型）
- **フック**: 「AI副業月30万はウソじゃないけど正直に言う」
- **展開**: 巷の情報に対して自分の実体験でツッコミを入れる
- **オチ**: 「だからわたしはこのやり方にした」で独自路線を提示
- **なぜ伸びるか**: 「煽り系に疲れた層」の共感。知的誠実さで差別化。[WebSearch済 note.com/freelife_creator]

## 4. 教育系ショート動画の伸びる型

### 主要フォーマット分析（[WebFetch済] college-sales.com・addness.co.jp・miraflow.ai）

#### 型1: ランキング型（「N選」「TOP3」）
- **構成**: フック（「衝撃のTOP3」）→ 3位→2位の順で期待感構築 → CTA → 1位発表
- **なぜ伸びるか**: 一覧は保存率2.5倍。「全部見なきゃ」の完了衝動。
- **使用指針**: 視聴者が知らないランキングほどよい（知っている内容は離脱）

#### 型2: Before/After型
- **構成**: 衝撃的な結果を先出し → 「なぜ変わった？」展開 → 過程・苦労 → 再度結果 → CTA
- **なぜ伸びるか**: 変化の可視化。期待感の維持。

#### 型3: PREP型（結論先出し）
- **構成**: 結論言い切り（3秒）→ 理由 → 具体例 → 再度結論強化
- **なぜ伸びるか**: 情報量が少ない + 論理的に整理されている = 完走率高い

#### 型4: 共感あるある型
- **構成**: 「〜あるある」日常の悩みを提示 → コミカルな描写 → 感情吐露 → コメント誘導
- **なぜ伸びるか**: 「これわかる」コメントが集まり拡散。エンゲージメント高い

#### 型5: 失敗談ストーリー型
- **構成**: 最悪の結末から始める → 原因分析 → 教訓 → 「気をつけて」注意喚起
- **なぜ伸びるか**: 感情移入しやすい。共感→コメント→拡散の連鎖

#### 型6: 検証・やってみた型
- **構成**: 仮説提示 → 検証プロセス早回し → 期待感 → 意外な結果発表 → 感想リクエスト
- **なぜ伸びるか**: 結果が気になって離脱できない。コメント「予想通りだった/違った」を誘発

## 7. hyui への最適化推奨

### 推奨する型 Top 3（理由付き）

#### 第1位: 「実録 Before/After 型」
- **型**: 「0円だったわたしが月14万になるまでにやった3つのこと」
- **理由**: hyui の実績（¥0 → ¥55,000 → ¥140,000）は最強のBefore/After素材。数字は全部実績ベースで倫理クリア。「嘘くさい副業系」との差別化ができる
- **フック例**: 「プログラミング未経験のわたしが2ヶ月でCWから月14万もらうようになった話、全部話します」
- **hyui のペルソナ合致度**: ◎（文系大学生×非エンジニア×実績ありの三拍子）

#### 第2位: 「失敗共有型」（等身大先輩フレーム）
- **型**: 「副業3週間0件だったときのわたしへ」「Claudeに頼んだら失敗した話」
- **理由**: hyui のペルソナ「1〜2歩先を行く先輩」に完全一致。失敗談は成功自慢より共感が集まる。「正直な発信者」ポジションを獲得できる
- **フック例**: 「副業0件が続いた3週間、何を間違えてたか今なら言える」
- **hyui のペルソナ合致度**: ◎

#### 第3位: 「プロンプト/操作1つ紹介型」（保存狙い）
- **型**: 「このClaude Code指示1個で〇〇が3時間から15分になった」（persona-hyui.mdの実績数字活用）
- **理由**: 「保存してください」型は中長期的なフォロワー獲得に効く。数字はpersona-hyui.md記載の実証値（3時間→15分、週3時間→0 等）を使えばハルシネーションゼロ
- **フック例**: 「提案資料が3時間かかってたのをClaudeに頼んだら15分になった。プロンプトそのまま貼ります」
- **hyui のペルソナ合致度**: ○（実績数字に強みあり）

### 避けるべき型 Top 3（理由付き）

#### 第1位: 権威先生キャラ系
- **NG例**: 「〇〇の専門家が教える」「プロが解説」「完全攻略」
- **理由**: hyui のペルソナは「1〜2歩先の先輩」。権威型は等身大感が崩れる。大学生という設定とも矛盾する。「先生」ポジに乗っても読者の天井が高く、失望離脱リスクが高い
- **代替**: 「先週やってみた」「わたしが詰まってたのはここ」型

#### 第2位: 煽り系・キラキラ収益自慢系
- **NG例**: 「月30万稼ぐ方法」「これで月収が変わった」（過剰表現）
- **理由**: 景表法リスク [WebSearch済]。hyui の信頼設計（「盛らない・全部公開」）と矛盾する。情報商材インフルエンサーと同列に見られると致命的。AI副業市場でのコモディティ化リスク [WebSearch済 sbbit.jp]
- **代替**: 「わたしの場合は月14万になった、それだけです」の事実報告型

#### 第3位: 技術解説先行型（エンジニア向け）
- **NG例**: 「Claude Code の SDK 使い方」「CLAUDE.md の設計」「プラグイン開発入門」
- **理由**: content-pipeline/CLAUDE.md に明記「NG主題: Claude Code新機能解説・SDK使い方・プラグイン紹介・技術比較ベンチマーク」。ターゲット（非エンジニア副業初心者）と噛み合わない
- **代替**: 「日本語で頼んだだけ」「コードわからなくても使えた理由」型

### 最初の10本で実験すべき型（フォロワー獲得期戦略）

[WebSearch済] 複数ソース統合（addness.co.jp / note.com/talented_renya / ownly.jp）

```
実験マップ（10本の割り当て案）

 #1: 自己紹介型「わたしがhyuiになった理由」（等身大先輩フレームの基礎確立）
 #2: Before/After型「プロフィール70字→450字で3スカウト来た話」（実績ベース）
 #3: 失敗談型「副業3週間0件だったとき何を間違えてたか」（共感確認）
 #4: プロンプト紹介型「応募文を3時間書いてた話→Claudeで15分」（保存誘発）
 #5: ランキング型「Claude副業で実際に使ったプロンプトTop3」（保存率テスト）
```

### 判定軸候補一覧

| # | 判定軸 | 説明 | 重み目安 |
|---|---|---|---|
| A | **等身大合致度** | 権威型ではなく「1〜2歩先の先輩」フレームになっているか。「わたしも同じだった」「先週やった」型か | 高 |
| B | **実績数字有無** | persona-hyui.md 記載の実証値（¥55K→¥140K / 3時間→15分等）を活用しているか。盛らない数字ベース | 高 |
| C | **非エンジニア明示度** | 「プログラミングゼロ」「日本語で頼んだだけ」「文系でも」フレームが自然に入っているか | 高 |
| D | **フック心理適合度** | 損失回避・直接呼びかけ・好奇心ギャップ・BI（Before/After）のいずれかを使っているか | 高 |
| E | **AI臭排除度** | 括弧多用・「これにより」連発・箇条書き過多・「〜ではないでしょうか」ゼロか | 中 |
| F | **保存誘発度** | 「プロンプトをコメントに貼ります」「手順を全部見せます」等、保存する理由があるか | 中 |
| G | **NG型回避** | 権威型・煽り型・技術解説先行型・キラキラ収益自慢型 を踏んでいないか | 高 |
| H | **完走設計** | 最後まで見させる構造（PREP/ランキング/結論先出し）になっているか。冒頭3秒NG起動なし | 中 |
