### 1.2 フック分類と効果（7+分類）

**科学的根拠（神経科学ベース）[WebFetch済]**
脳が最初3秒に自動処理する3つの問い：「これは自分に関係あるか」「見る価値があるか」「何の得があるか」。
- **ボトムアップ処理**：急激な変化・予期しないパターン・新奇性に反応する自動プロセス
- **情報ギャップ理論**：既知と未知の間の溝が脳に不快感を引き起こし、コンテンツ消費でのみ解決されるため視聴を継続させる

**フック分類 全9タイプ [WebSearch済][WebFetch済]**

| タイプ | 心理メカニズム | 具体例 | 効果・特性 |
|---|---|---|---|
| **疑問型（Question）** | 脳の疑問解決欲求を刺激 | 「なぜ毎日投稿してるのに伸びないのか？」 | 特定の悩み/願望/知識ギャップを狙う時に有効。答えが「ただのトリビア」だと弱い |
| **矛盾型・逆張り型（Contradiction）** | 認知的不協和・脳の予測エラーシステムを刺激 | 「みんなは毎日投稿と言う。それは間違い」 | 強力だが実際に支持できる内容がある場合のみ使用。単公式上限60%、他パターンと組み合わせで90%に到達可能 |
| **数字型（Specific Number）** | 認知ショートカット・達成欲求の活性化 | 「3,247本の投稿を分析。機能した4つの法則は…」 | 奇数（3, 5, 7）が特に効果的。漠然な表現より具体数値が信頼性・真正性を暗示 |
| **告白型・個人的告白（Confession）** | ミラーニューロン・共感回路の活性化（pratfall効果） | 「月3万しか稼げなかった頃の話をします」 | 感情的つながりと信頼構築に強い。完璧なスペックより人間的なプラットフォームの方が刺さる |
| **ビジュアル型（Visual Shock）** | パターン割り込み（ボトムアップ注意）を発生させる | 異常なビフォーアフターの映像を冒頭に出す | 言葉なしで視覚だけで止まらせる。ファセスチャンネル・料理・DIYに特に有効 |
| **宣言型・命令型（Imperative）** | 強制的な行動指示で脳の実行機能を刺激 | 「投稿前に必ず見て」「止まれ」「聞いて」 | 最も攻撃的・二分的。高リスク情報でのみ推奨。過剰使用で信頼失墜 |
| **物語導入型（Story/Micro-story）** | ナラティブ運動量を生み出す | 「去年の今頃、俺はフォロワー0だった」 | 感情的弧を作るため長尺向き。短尺では「ミニクリフハンガー」として使う |
| **共感型（Empathy）** | 視聴者の現在の痛みを言語化 | 「SNS毎日更新してるのに、全然再生数伸びなくて焦ってない？」 | PAS構成のフックとして機能。共感からスタートして解決提示へ繋ぐ |
| **成果実証型（Before/After Snapshot）** | 進歩への脳の愛着と社会的証明 | 「67日間で2,300フォロワー→23,000人になった方法」 | 達成可能性の希望を生成。変身コンテンツに特に相性良し |

**組み合わせの効果 [WebSearch済]**
単一パターンのリテンション上限は約60%。2パターン組み合わせると90%に到達可能（心理トリガーの重ね掛け）。例：「矛盾型×数字型」→「毎日投稿をやめた。その結果、再生数が3倍になった理由」

**フックの長さ目安 [WebSearch済]**
- 最初の言葉/ビジュアル：即座に着弾（0秒）
- フック本体：1-2秒（5-8語/英語）、5-6秒が最長の弧
- 日本語目安：字幕として15字以内が理想（6インチスマホ画面での可読性）
- 最強のフックは「短い1文」で完結する

## 2. 台本の構成型

### 2.1 主要6構成テンプレート（詳細）

**① Hook-Value-CTA（基本型）[WebFetch済]**

```
[Hook: 0-3秒] 注意喚起
[Value/Body: 3-50秒] 価値提供（フックの約束を即座に実行）
[CTA: 50-60秒] 明確な次のアクション
```

- 秒数比率（TikTok）：3 : 22 : 5 ＝ Hook10% : Body73% : CTA17%
- 適用：初心者向け、全プラットフォーム対応
- 注意：Bodyで「無駄な情報を一切入れない」が鉄則

---

**② AIDA（製品・ブランド認知型）[WebFetch済]**

```
[A: 0-3秒] Attention — 即座に注意を掴む
[I: 3-8秒] Interest — 興味の維持
[D: 8-20秒] Desire — 欲求・感情の喚起
[A: 最後3-5秒] Action — CTA
```

- 総尺：15-30秒
- 最適用途：製品ローンチ、販売型コンテンツ、ブランド認知
- 特性：感情的な弧を通じて購買決定へ誘導する設計

---

**③ PAS（問題解決・共感型）[WebFetch済]**

```
[P: 0-3秒] Problem — 視聴者が共感する問題を提示
[A: 3-8秒] Agitate — 問題の深刻さを拡大・刺激
[S: 8-20秒] Solution — 解決策を提示
```

- 総尺：15-30秒（TikTok最適）
- 最適用途：ペインポイント駆動、問題解決チュートリアル、サービスプロモーション
- PAS vs BAB比較：PASは「即座の痛み」、BABは「変身願望」に効く

---

**④ BAB（変身・ビフォーアフター型）[WebFetch済]**

```
[Before: 0-10秒] 問題状態を描写
[After: 10-20秒] 改善後の状態を提示
[Bridge: 20-45秒] 変身を実現した方法・解決策
```

- 総尺：35-60秒
- 最適用途：変身コンテンツ、製品デモ、DIY、メイクアップ
- 効果：**平均120%エンゲージメント増加**（virvid.ai調査）
- 日本語の例：「底辺YouTuberが1ヶ月で月100万達成」（ギャップ型の最強パターン）

---

**⑤ PSP（アルゴリズム最適化型・2025年専用）[WebFetch済]**

```
[P: 0-3秒] Pattern interrupt — 既存パターンを破る
[S: 3-23秒] Story — ミニクリフハンガーを含む展開
[P: 23-30秒] Payoff — 明確なCTA
```

- 総尺：30秒
- 特性：2025年以降の短尺アルゴリズムに特化設計。視聴完了率を最大化
- 3秒フック＋ミニクリフハンガーの組み合わせが特徴

---

**⑥ PASTOR（複雑オファー・高額商品向け）[WebFetch済]**

```
[P] Problem — 問題・共感
[A] Amplify — 緊急性を増幅
[S] Story — 解決策の導入ストーリー
[T] Transformation — 変容の利益説明
[O] Offer — 具体的オファーの提示
[R] Response — CTA
```

- 総尺：60-90秒
- 最適用途：複雑な製品、高額オファー、ケーススタディ
- 最適プラットフォーム：YouTube Shorts（Reels・TikTokには長すぎる場合あり）

---

**プラットフォーム×構成型の使い分け一覧 [WebFetch済]**

| プラットフォーム | 最適秒数 | 推奨構成 | リテンション目標 |
|---|---|---|---|
| TikTok | 13秒 or 60秒 | Hook-Value-CTA / PAS / PSP | 60%以上 |
| Instagram Reels | 7-30秒 | BAB / AIDA | 3秒リテンション最優先 |
| YouTube Shorts | 50-60秒 | Hook-Value-CTA / PASTOR / AIDA | 50%以上（engaged views重視） |

### 2.2 言葉数・秒数の比率目安

## 3. リテンション設計

### 3.1 ループ動画の仕組み

**シームレスループの設計 [WebSearch済]**
- 動画の終わりと始まりを自然につなぐことで、視聴者が再生終了に気づかずに繰り返し視聴する
- ループ再生がリプレイカウントとして計上され、アルゴリズム評価を大幅に押し上げる
- 「リプレイ率 1.2 超」でアルゴリズムの分配が大幅に拡大（retensis調査）

**ループが有効なコンテンツタイプ：**
- 結末が驚き → 「え、さっきのもう一回」となる構成
- クリフハンガーループ：物語の緊張が解決点に戻っていく構造
- ビジュアルループ：視覚的に繰り返し見たくなるシーン

### 3.2 Cliffhanger / Curiosity Gap / Curiosity Stacking

**情報ギャップ理論（Curiosity Gap）[WebFetch済]**
既知と未知の間に「溝」を作ることで脳が不快感を経験し、コンテンツ消費によってのみ解決される。視聴者は「解決したい」という衝動で動画を最後まで見る。

**Cliffhanger設計 [WebSearch済]**
- 緊張の瞬間を作り、解決せずに次のセクションへ
- トップパフォーマーは「一つの問いが答えられると同時に別の問いが生じる」多重構造を採用
- 技術名：**Curiosity Stacking**（好奇心の積み重ね）

**Curiosity Stacking の流れ：**
```
問い① 提示 → 答え①（＋新たな問い②が同時発生）→ 答え②（＋問い③）→ ... → 最終解決 → CTA
```

**注意：ギャップのサイズ = ペイオフのサイズ [WebSearch済]**
「衝撃の事実」と予告して実際が平凡だと、アルゴリズムが「時間を無駄にさせるコンテンツ」と評価し、将来の分配を大幅に減らす。

## 4. CTA設計

### 4.1 コメント誘発の仕組み

**有効なコメント誘発CTA [WebSearch済]**
1. **特定・開放型の質問**：「あなたが一番困ったシーンはどこでしたか？」
2. **キーワードコメント誘導**：特定ワードをコメントさせる（プラットフォーム内インタラクションとしてアルゴリズムに強い信号）
3. **賛否両論の問いかけ**：意見が分かれる話題で自然なコメント合戦を生む
4. **教えてもらう型**：「あなたの経験を聞かせて」（ユーザーが情報提供者になる）

### 4.2 フォロー誘発の構造

- **価値の予告型**：「次回は〇〇を教えます。フォローしてないと見逃す」
- **シリーズ化**：「Part 2」の予告で続きへの期待を作る
- **保存促進型**：「あとで使えるからスクショ・保存して」（保存はInstagramでは最強シグナル）

**YouTubeのフォロー信号 [WebSearch済]**
「Shortを見てからチャンネル登録」「そのままチャンネルページへ移動」はアルゴリズムへの非常に強いポジティブシグナル。

### 4.3 リンク・概要欄誘導の効果

**短尺での弱さ [WebSearch済]（一般知見との整合）**
- 短尺動画からの外部リンク誘導は効率が低い（TikTok/Reelsは基本的に外部リンクがビデオ内に貼れない）
- 「プロフィールのリンクへ」は視聴者の行動コストが高く離脱率が上昇
- YouTube Shortsは概要欄リンクが使えるが、モバイル視聴では気づかれにくい

### 4.4 「次回予告」型の効果

- Series型コンテンツでは高い効果（フォロー→次回通知の流れを作る）
- 5〜8秒のティーザーを有料・無料広告として使う手法も有効
- ただし、予告内容が本編と乖離すると信頼を失う

**デュアルデリバリー推奨 [WebSearch済]**
CTAは「音声+字幕テキストオーバーレイ」の両方で届ける。音声なし視聴者と音声あり視聴者の両方をカバー。動画の自然な一時停止地点に配置する。

## 5. テンポ・編集要素

### 5.1 1秒あたりの言葉数の目安

| 言語 | 推奨 WPM | 30秒の語数目安 |
|---|---|---|
| 英語（TikTok/Reels） | 160-185 WPM | 80-92語 |
| 英語（YouTube Shorts） | 140-160 WPM | 70-80語 |
| 日本語（推測・要検証） | 200-240字/分 | 100-120文字 |

**日本語補足 [WebSearch済]**
- 日本語話者の平均発話速度は200+ WPM（音節密度が高い）
- CPM（characters per minute）ベースでの計算が実用的
- ツールによるサポートあり（wordtotime.org等）
- 「情報量/秒」は英語より低いため、日本語ショートは1秒あたりの情報密度に注意が必要

### 5.2 カット頻度

**推奨カット間隔 [WebSearch済][WebFetch済]**
- TikTok/Reels最適：**2-3秒に1カット**（視覚刺激を与え続ける）
- YouTube Shorts：2-4秒ごとのカット挿入、5-7秒ごとの映像・ストーリー変化
- カット以外の「変化」手段：ズームイン/アウト、テキストオーバーレイ、手のジェスチャー、BGMの変化

**過剰なエフェクトはNG [WebSearch済]**
過度なトランジション・ズーム・派手なエフェクトは「プロっぽく見せる」どころか、動画をごちゃごちゃに見せる逆効果。

### 5.3 BGM・効果音の影響

**音声要素の効果 [WebSearch済]**
- 音声の特性（スピードの速さ・ピッチ・ラウドネス・感情的喚起）がエンゲージメントに影響
- 適度なスピード、ピッチ、ラウドネス、感情的喚起レベルが高エンゲージメントにつながる
- 感情的バレンス（ポジティブ感情）は線形効果：よりポジティブな感情表現ほどエンゲージメントが高い
- 楽曲の「記憶に残るイントロ/フック」で即座に注目を集め、スキップを防ぐ

**音声の重要シグナル [WebSearch済]**
TikTok 2025以降：発見の84%が検索経由に変化。トレンドサウンドより「検索キーワードとの整合性」が重要度を増している。

### 5.4 字幕の役割（再掲・整理）

- **音声オフ視聴対応**：69-85%の視聴が音声なし（公共の場など）
- **フック強化**：テキストと音声の二重刺激で記憶定着率向上
- **SEO**：TikTok検索発見の増加に対してキャプション内キーワードが有効（84%が検索経由）
- **字幕スタイル**：TikTokはアニメーション型、YouTubeは従来フルテキスト型が好まれる

## 6. 失敗パターン（添削で潰すべきNG）

### 6.1 台本レベルのNG

| NGパターン | 問題の説明 | 対策 |
|---|---|---|
| **前置き・自己紹介から入る** | 視聴者には関係ない情報で3秒を消費する。即離脱 | フックを最初の1文に置く。自己紹介はBody以降か使わない |
| **「今日は〇〇について話します」** | 何を話すか予告するだけで価値がない。「で、何が得になるの？」という疑問が先に来る | 価値/問い/驚きを先に出して後で「この話は〇〇についてです」を省略 |
| **オチが弱い/結論が薄い** | 好奇心ギャップを作ったのにペイオフが平凡。アルゴリズムが「時間を無駄にした」と評価 | フックで約束した価値より少し多く届ける設計にする |
| **1本に複数メッセージを詰め込む** | 「企画が9割」の原則に反する。視聴者が何を得られるかが不明確になる | 1本1テーマ・1メッセージを徹底する |
| **説明過多・情報密度が高すぎる** | 吸収しきれない情報量で視聴者がついていけなくなり離脱 | 1-3つのキーポイントに絞る（教育動画でも最大3） |
| **自分ごと化できないフック** | 「こんな人は少ない」「特殊なケース」から入ると視聴者が「私には関係ない」と判断 | ターゲットの具体的な悩み・状況を言語化してフックに置く |

### 6.2 AI生成丸出し台本のサイン

| サイン | 説明 |
|---|---|
| **汎用的な書き出し** | 「最近、AIが注目されていますね」「今回は〇〇について解説します」—個性も文脈もない書き出し |
| **ブランド固有のカスタマイズがない** | 自分のキャラクター・過去のエピソード・独自の視点がゼロ。誰でも書けるテンプレ感 |
| **断言しすぎ/確信度が均一** | 全文が「〜です。〜します」の同じトーンで続く。人間は強弱をつけて話す |
| **短い文の連続** | AI台本の特徴的パターン。「〜です。〜です。〜です。」の羅列でリズムが単調 |
| **文化的文脈の欠如** | 日本の時事ネタ・自分のコミュニティで共有されている文脈が入らない |
| **感情的な起伏がない** | 怒り・驚き・共感・笑いが構造として設計されておらず、平板な情報列挙になる |
| **CTAが汎用的** | 「いいね・チャンネル登録お願いします」系の定型文。なぜフォローすべきかの根拠がない |

### 6.3 構造・編集レベルのNG

- **開始が遅い**：静止画・テキスト導入・ロゴアニメーションで最初の3秒を消費
- **モバイル非最適化**：テキストが6インチ画面で読めない、16:9横動画を縦に変換しただけ
- **全プラットフォーム共通内容**：同一動画をTikTok/Reels/Shortsに投稿 → リーチ150-300%低下（reezo.ai調査）
- **過剰なエフェクト・トランジション**：「プロっぽく見せたい」という意図が逆効果になる
- **音声とビジュアルのテンポ不一致**：高エネルギーBGMに対してゆっくりした編集リズム
- **外部リンク誘導に頼りすぎる**：短尺では視聴者の行動コストが高い。「プロフィールのリンクへ」は弱い

### 6.4 日本市場特有の失敗（[WebFetch済] + [第三者ソース経由]）

- **AIナレーション丸出し**：日本の視聴者はAI音声への忌避感が強い。人間の生の声の優位性が顕著
- **同一テンプレートの大量投稿**：類似動画に対する視聴者の疲弊が早い
- **ランキング動画の陳腐化**：かつて最も視聴完了率が高かったジャンルだが、AI大量生成で飽和傾向
- **YouTube収益化のAI規制**：AIナレーションのみ・AI音声のみの動画は収益化制限の対象になりつつある

## 7. スコアリングへの示唆（添削判定軸・候補）

以下は本リサーチから抽出できる、台本スコアリング・添削スキルで使える判定軸の候補10項目。

### 判定軸 #1：フック速度チェック（0-3秒ルール）
```
判定：最初の1文（または最初の15文字以内）に「疑問/矛盾/数字/共感」のいずれかが存在するか？
OK基準：1文目が価値・問い・驚きのいずれかで始まる
NG基準：「今日は〇〇について」「最近〇〇が話題ですね」「こんにちは、〇〇です」
スコア：+20点（存在）/ -10点（前置き1文以上）
```

### 判定軸 #2：フックの心理トリガー分類
```
判定：フックが9分類（疑問/矛盾/数字/告白/ビジュアル/宣言/物語/共感/成果実証）のどれに該当するか？
OK基準：2パターン以上の組み合わせ → リテンション90%域狙い可
NG基準：0パターン（分類不能な汎用文）
スコア：2パターン組み合わせ +10点ボーナス
```

### 判定軸 #3：フック語数・長さ
```
判定：フック（最初の1文）が15字以内（日本語）/8語以内（英語）に収まるか？
OK基準：15字以内で疑問/驚き/価値を提示できている
NG基準：フック文が30字超 → スマホ1画面で読み切れず視線が切れる
```

### 判定軸 #4：1本1テーマ原則
```
判定：台本全体を通じてメインメッセージが1つに絞られているか？
OK基準：「この動画を一言で言うと〇〇」が即答できる
NG基準：複数のノウハウ・複数のCTAが混在
スコア：-15点（2テーマ以上を詰め込んだ場合）
```

### 判定軸 #5：秒数比率チェック
```
判定：Hook : Body : CTA の比率が適正範囲内か？
TikTok標準：(3秒以内) : (10-22秒) : (3-5秒) = 30秒以内
OK基準：Hook 10-15% / Body 70-80% / CTA 10-17%
NG基準：Hook 30%超（前置きが長い）/ CTA 0%（行動指示なし）
```

### 判定軸 #6：Curiosity Stackingの存在
```
判定：Body中に「答えが出た瞬間に次の問いが生まれる」構造が1箇所以上あるか？
OK基準：本文中に問いの提示→答えの途中→別の問い示唆 の流れがある
NG基準：一直線の情報列挙（問いがなく答えを並べ続ける構造）
```

### 判定軸 #7：CTA特異性スコア
```
判定：CTAが「いいね・チャンネル登録お願いします」以外の具体的行動を促しているか？
OK基準：特定の質問への回答/特定キーワードのコメント/保存の具体理由提示
NG基準：汎用的な「フォローよろしく」「コメントください」のみ
スコア：具体的CTA +10点 / 汎用CTA -5点 / CTAなし -15点
```

### 判定軸 #8：AI臭チェック（4サイン検出）
```
判定：以下のAI生成サインが台本内にあるか？
NG対象：
  - 「今回は〇〇について解説します」系の導入
  - 短文羅列（「〜です。〜です。〜です。」3連続以上）
  - ブランド固有情報（自分の経験・エピソード・数字）がゼロ
  - 感情変化が台本内に1箇所もない
スコア：上記1サイン検出ごとに -5点
```

### 判定軸 #9：ペイオフ強度チェック
```
判定：フックで約束した価値をBodyが十分に「回収」しているか？
OK基準：フックで提示した問い・驚き・期待に対して、具体的で実行可能な答えが提供されている
NG基準：「気になる方は調べてみてください」「詳しくはプロフィールへ」でフックの借りを返さない
スコア：完全回収 +15点 / 部分回収 0点 / 未回収 -20点
```

### 判定軸 #10：自分ごと化チェック
```
判定：フック〜Body冒頭でターゲット視聴者が「これは自分の話だ」と感じられる具体性があるか？
OK基準：特定の職業/状況/感情/数値で視聴者を「選別」している（例：「副業でAI使ってる人限定」）
NG基準：「みんなが知りたい情報」「誰でも使える」系の汎用ターゲット設定
スコア：具体ターゲット明示 +10点 / 汎用ターゲット -5点
```
